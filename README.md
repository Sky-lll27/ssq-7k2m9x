# 双色球随机选三注（网页版）

**一句话**：点一下出 3 注随机号码（每注 6 红球 + 1 蓝球）。你再加 1 注自选、1 注机选，凑成每期 10 元。规则写在页面里、随网页一起托管，任何设备打开同一个网址都是同一套规则。选号完全在你自己浏览器里算，不联网、不调模型、不消耗 token。

## 2. 日常怎么用（3 步）

1. 打开网址（或双击本地 `index.html`）——页面自动出三注
2. 想换一批：点红色大按钮 **「一键选三注」**（可以一直点）
3. 点 **「一键复制三注」** → 粘贴到备忘录或照着买
   - 复制失败时（少数浏览器/本地打开会限制），长按下方文本框全选，再手动复制

页面固定提示：**本页3注共6元；加1注自选、1注机选，共10元。**
每次还会显示本次三个蓝球，方便你的自选注避开它们（机选不用管）。

## 3. 选号规则（页面「选号规则说明」里同样有）

1. 每次 3 注，每注 6 个红球 + 1 个蓝球
2. 红球从 01–33 随机取，单注内不重复，展示时升序，号码补齐两位数
3. 蓝球从 01–16 随机取，**三注蓝球互不相同**
4. 红球全范围开放，**没有任何禁选号码**
5. 不筛冷热、遗漏、奇偶比、大小比、区间比例；允许连号、同尾号
6. 三注红球允许重叠，「避免过分相似」明确为：**任意两注最多重叠 4 个红球**
7. 三注完整组合不重复
8. 随机用浏览器 `crypto.getRandomValues` + 拒绝采样（避免取模偏差），先生成候选组合再按跨注约束筛选
9. 这些规则只用于**随机选号和适度分散**，**不能提高中奖概率，也不能预测开奖**

购买原则：低频随缘；奖池不设购买门槛；不因奖池大或派奖增加预算。
